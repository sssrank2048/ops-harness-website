# 多技能引用与工作流配置验收

日期：2026-10-09。macOS arm64，Node.js 24.19.0、pnpm 11.19.0；生产构建使用真实 Google Chrome 154.0.8037.98（Playwright 驱动）验收。测试使用临时 loopback 服务及隔离内容、发布、统计目录，密码在内存生成并经环境变量注入。

- `pnpm check`：类型检查与 96 项测试通过；其中 10 项知识库集成测试覆盖多技能注册及同名替换、引用存在性、下架条目的删除保护、迁移备份与重启、任意工作流名称及边界、技能数量限制、较大目录回读、下载缓存和原有上传/鉴权校验。
- `pnpm build`：通过。
- 浏览器一次选择两个技能文件上传，创建知识库引用两者并填写第四个自定义中文工作流名称；保存、刷新后名称、值和引用保持一致。
- 工作流重复名称被阻止保存；新增、删除行可正常保存，也可移除全部工作流，并显式保存空技能引用。
- 同名上传更新文件，下载取得新字节，已有知识库引用保留。两个知识库分别引用不同技能，选择相互独立，在用技能移除按钮禁用。
- 三文件批次包含一个超出 5 MiB 的文件：两个有效文件保存，中间文件单独报告失败；上传期间的未保存知识库输入保持不变，后续保存成功。
- 无引用技能可通过应用内确认框移除。Enter 打开、Escape 取消且返回触发按钮；切换知识库时取消放弃修改也保留表单和焦点。
- 模拟另一管理员在本次保存完成、浏览器接收响应前更新同一知识库：本页下一次保存返回预期 409，未覆盖对方内容，当前输入保留。保存响应直接更新本地条目及 revision，不再通过额外 GET 前移版本号。
- [1440px 桌面截图](desktop.png)与 [390px 窄屏截图](mobile.png)已检查；无横向溢出，减少动态效果模式下正常。图片库与知识库之间切换、再次回读正常。
- 最终浏览器流程观察到 55 条页面、资源和业务响应；除刻意构造的一个 409 冲突外均成功，没有其他 Console 或页面错误。
